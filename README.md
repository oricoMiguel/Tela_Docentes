# ControleHoras — Dashboard de Gestão de Horas

## Sobre o projeto

O ControleHoras é uma aplicação web desenvolvida em grupo durante o 3º semestre do curso de Análise e Desenvolvimento de Sistemas, como parte de um projeto de extensão acadêmica.

O objetivo do sistema é facilitar o acompanhamento das horas dedicadas a projetos de extensão, permitindo visualizar a carga horária acumulada, o progresso em relação a uma meta e o status dos projetos.

O front-end foi concluído, incluindo a interface do dashboard e a apresentação das informações dos projetos. Devido às limitações de tempo durante o desenvolvimento acadêmico, a integração com o back-end não foi finalizada.

## Funcionalidades da interface

- Dashboard com total de horas acumuladas.
- Indicador visual de projetos concluídos.
- Barra de progresso em relação à meta de horas.
- Tabela de projetos com professor responsável, semestre, status e carga horária.
- Indicadores visuais para projetos pendentes e validados.
- Interface para acesso aos detalhes dos projetos.
- Elemento de interface para exportação de relatórios em PDF.

**Observação:** as funcionalidades que dependem de serviços de back-end podem não estar operacionais, pois a integração não foi concluída.
